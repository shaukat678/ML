# 3. The Most Important Scikit-learn Pattern

Almost everything follows some variation of:

```text
CREATE
   ↓
FIT
   ↓
TRANSFORM / PREDICT
   ↓
EVALUATE
```

For example:

```python
model = LinearRegression()

model.fit(X_train, y_train)

predictions = model.predict(X_test)
```

This simple pattern is the heart of Scikit-learn.

---

# 4. What Does `fit()` Mean?

This is probably the single most important word in Scikit-learn.

```python
model.fit(X_train, y_train)
```

means:

> **Let the algorithm learn from the training data.**

It doesn't mean:

> "Run the model."

It means:

> **Learn the parameters/patterns necessary to perform the task.**

---

# 5. Example: Linear Regression

Suppose:

```text
Study Hours → Exam Score
```

Data:

| Hours | Score |
| ----: | ----: |
|     1 |    45 |
|     2 |    50 |
|     3 |    58 |
|     4 |    65 |
|     5 |    72 |

We create:

```python
X = df[["Hours"]]
y = df["Score"]
```

Then:

```python
model = LinearRegression()
```

Then:

```python
model.fit(X, y)
```

The model learns something approximately like:

$$
Score = \beta_0 + \beta_1 Hours
$$

For example:

$$
Score = 38 + 7Hours
$$

The exact values depend on the data.

---

```python

```

and:

```python

```

For example:

```text

```

So approximately:

$$
Score = 37.8 + 7.1(Hours)
$$

# 9. Why Does `X` Usually Have Two Dimensions?

This confuses beginners a lot.

Suppose we have:

```python
X = [1, 2, 3, 4, 5]
```

This is a 1D structure.

But Scikit-learn generally expects:

```text
(samples, features)
```

So we want:

```text
[[1],
 [2],
 [3],
 [4],
 [5]]
```

Shape:

```python
X.shape
```

gives:

```text
(5, 1)
```

Meaning:

```text
5 samples
1 feature
```

# 13. Estimators

Now we encounter an important Scikit-learn term:

# Estimator

An estimator is an object that can **learn from data** using `.fit()`.

Examples:

```python
LinearRegression()
RandomForestRegressor()
LogisticRegression()
StandardScaler()
SimpleImputer()
```

They don't all do the same thing, but they follow the Scikit-learn API.

---

# 14. Why Is This Useful?

Because different algorithms feel similar to use.

### Linear Regression

```python
model = LinearRegression()

model.fit(X_train, y_train)

pred = model.predict(X_test)
```

### Random Forest

```python
model = RandomForestRegressor()

model.fit(X_train, y_train)

pred = model.predict(X_test)
```

Notice the pattern?

```text
create
 ↓
fit
 ↓
predict
```

The underlying mathematics is completely different.

But the interface is similar.

That's one of Scikit-learn's biggest strengths.

# 15. Transformers

Not everything predicts.

Some objects **transform data**.

For example:

```python
StandardScaler()
```

You can do:

```python
scaler = StandardScaler()

scaler.fit(X_train)

X_train_scaled = scaler.transform(X_train)
```

Here:

```text
fit()
```

learns:

$$
\mu
$$

and:

$$
\sigma
$$

from the training data.

Then:

```text
transform()
```

applies:

$$
z = \frac{x-\mu}{\sigma}
$$

---

# 16. Estimator vs Transformer

This distinction is extremely useful.

### Estimator

Learns something.

```text
.fit()
```

Examples:

```text
LinearRegression
RandomForest
LogisticRegression
```

---

### Transformer

Learns a transformation and changes the data.

```text
.fit()
.transform()
```

Examples:

```text
StandardScaler
OneHotEncoder
SimpleImputer
PCA
```

---

# 17. `fit_transform()`

Because this combination is common:

```python
X_train_scaled = scaler.fit_transform(X_train)
```

is equivalent conceptually to:

```python
scaler.fit(X_train)

X_train_scaled = scaler.transform(X_train)
```

But don't do this to test data:

```python
scaler.fit_transform(X_test)
```

Instead:

```python
X_test_scaled = scaler.transform(X_test)
```

Why?

Because the test data must not influence what the preprocessing step learned.

---

# 18. Why This Matters

Suppose training data:

```text
10
20
30
40
```

The scaler learns:

```text
mean = 25
```

Now test data:

```text
50
60
```

We should transform test values using:

```text
mean = 25
```

not calculate a new test mean.

So:

```text
TRAIN
 ↓
fit
 ↓
learn parameters

TEST
 ↓
transform
 ↓
use those parameters
```

# 27. `score()`

Many Scikit-learn estimators provide:

```python
model.score(X_test, y_test)
```

But ⚠️ be careful.

The meaning depends on the estimator.

For example, for many regression estimators:

```text
score()
```

returns:

$$
R^2
$$

For many classifiers, it commonly returns:

```text
accuracy
```

So don't blindly use `.score()` without knowing what metric it represents.

For serious evaluation, it's often clearer to explicitly use:

```python
mean_squared_error()
r2_score()
accuracy_score()
precision_score()
recall_score()
f1_score()
```

# 30. One Huge Concept: The Model Doesn't "Understand" the Data

When we say:

> "The model learned."

Don't imagine human-like understanding.

It learns numerical parameters/patterns according to its mathematical objective.

For example, Linear Regression learns coefficients:

$$
\beta_0,\beta_1,\beta_2,\ldots
$$

A decision tree learns:

```text
Distance < 5?
       │
   ┌───┴───┐
  Yes      No
```

A neural network learns:

```text
weights + biases
```

Different models learn different kinds of mathematical representations.

---

# 31. The ML Learning Loop

Almost every supervised learning algorithm can be viewed conceptually as:

```text
             DATA
               ↓
        Make predictions
               ↓
        Compare with truth
               ↓
             ERROR
               ↓
        Adjust parameters
               ↓
        Make better predictions
               ↓
             repeat
```

This is the fundamental idea behind learning.

The exact mechanism differs between algorithms.

---

# 32. Example: Linear Regression

We want:

$$
\hat y = \beta_0 + \beta_1x
$$

Initially the parameters aren't optimal.

Predictions:

```text
Actual:     100
Predicted:   70

Actual:     200
Predicted:  150
```

Calculate error.

Then find parameters that minimize an objective such as:

$$
MSE = \frac{1}{n}\sum(y_i-\hat y_i)^2
$$

Eventually:

```text
predictions
     ↓
errors become smaller
```

That's the learning process.

# 34. A Tiny Complete Example

Let's make the simplest possible ML model.

```python
import numpy as np

from sklearn.linear_model import LinearRegression

X = np.array([
    [1],
    [2],
    [3],
    [4],
    [5]
])

y = np.array([
    3,
    5,
    7,
    9,
    11
])

model = LinearRegression()

model.fit(X, y)

prediction = model.predict([[6]])

print(prediction)
```

What relationship is the model learning?

$$
y = 2x+1
$$

So for:

$$
x=6
$$

we expect:

$$
y=13
$$
