# 5. Series

A **Series** is essentially one labeled column.

For example:

```python
import pandas as pd

ages = pd.Series([20, 22, 21, 23])
```

It looks approximately like:

```text
0    20
1    22
2    21
3    23
dtype: int64
```

The left side:

```text
0
1
2
3
```

is the **index**.

The right side:

```text
20
22
21
23
```

is the data.

Think:

```text
Series = one column + index
```

---

# 6. Give the Series a Name

You can specify:

```python
ages = pd.Series(
    [20, 22, 21, 23],
    name="Age"
)
```

Now conceptually:

```text
Index    Age
0        20
1        22
2        21
3        23
```

# 12. Why Double Brackets?

Think of:

```python
df["Age"]
```

as:

> Give me one column.

While:

```python

```

means:

> Give me a list of columns.

The outer `[]` is DataFrame selection.

The inner `[]` is the Python list containing column names.

# 47. Pandas vs NumPy

This distinction is important.

| NumPy                        | Pandas                |
| ---------------------------- | --------------------- |
| Numerical arrays             | Tabular/labeled data  |
| `ndarray`                    | `DataFrame`, `Series` |
| Fast mathematical operations | Data manipulation     |
| Matrix operations            | Rows/columns          |
| Broadcasting                 | Filtering/grouping    |
| Linear algebra               | CSV/database data     |
| Numerical computation        | Data cleaning         |

But they're not competitors.

Think:

```text
             Python
                │
       ┌────────┴────────┐
       ↓                 ↓
    NumPy              Pandas
       │                 │
 Numerical math      Data handling
       │                 │
       └────────┬────────┘
                ↓
              ML
```

Pandas itself uses NumPy heavily under the hood.
